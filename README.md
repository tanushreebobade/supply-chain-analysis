
# End-to-End Supply Chain Analysis

## Project Overview
This project analyzes supply chain operations to understand delivery delays, profitability, shipping performance, and delivery risk using Python.

## Objectives
- Analyze shipping and delivery performance.
- Explore late delivery patterns.
- Evaluate profitability and business KPIs.
- Visualize operational trends.
- Build a Random Forest classification model.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- imbalanced-learn
- Jupyter Notebook

## Project Workflow
1. Data loading and cleaning
2. Exploratory Data Analysis (EDA)
3. Feature engineering
4. Business KPI analysis
5. Data visualization
6. Machine learning and model evaluation

## Initial Model Results
- Accuracy: 74%
- Precision: 79%
- Recall: 75%

These are initial notebook results and require further validation.

## Dataset
The project uses the DataCo Supply Chain dataset. The main dataset file is not included because of its size.

Place the dataset CSV in the same folder as the notebook before running the project.

## How to Run
1. Install Python and Jupyter Notebook.
2. Install dependencies:

   `pip install pandas numpy matplotlib seaborn scikit-learn imbalanced-learn`

3. Place the dataset CSV in the notebook folder.
4. Open `Supply_Chain_Analysis.ipynb`.
5. Run the notebook cells in order.
